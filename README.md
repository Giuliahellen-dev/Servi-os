# SIGNALS - Serviços de Acessibilidade

Funcionalidade de cadastro e gerenciamento de serviços de acessibilidade do projeto SIGNALS.

## 📌 Sobre o projeto

O SIGNALS é uma proposta de plataforma voltada à inclusão de pessoas surdas em eventos culturais.

Esta parte do projeto é responsável pelo gerenciamento dos serviços de acessibilidade oferecidos pela plataforma.

## ⚙️ Funcionalidades

- Cadastrar serviços de acessibilidade;
- Visualizar serviços cadastrados;
- Editar serviços;
- Excluir serviços.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- JSONServer
